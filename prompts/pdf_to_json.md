Jesteś precyzyjnym analitykiem finansowym. Przeanalizuj poniższy tekst sprawozdania finansowego spółki i wyciągnij kluczowe dane finansowe.

Zwróć WYŁĄCZNIE poprawny obiekt JSON o dokładnie takiej strukturze:
{
  "ticker": "CDR",
  "period": "Q4 2025",
  "revenue": 0,
  "ebit": 0,
  "net_profit": 0,
  "operating_cash_flow": 0,
  "equity": 0
}

Zasady:
- Wartości numeryczne wpisuj jako liczby (bez "zł", "PLN", czy spacji).
- Jeśli brak danych, wpisz null.
